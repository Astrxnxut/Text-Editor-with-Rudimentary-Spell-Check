How to open and run maven project:
	1. Import project into eclipse
	
	2. Click the arrow next to the run button
	
	3. There should be a run configuration at the top called text-editor
	
	4. If this configuration does not exist, go to run configurations...
	and create a new maven build run configuration. Make sure to put
	"javafx:run" in the goals of that configuration, but without the quotes.
	
How to open a text file:
	1. Open the app
	
	2. Click the file menu in the top left, then in the dropdown click open.
	The app will then show a file chooser where to can go to a file you 
	would wish to open, but only text files are able to be selected.
	
	3. If the user wishes to cancel opening a file, it goes back to how it was before
	without changing anything and without producing any errors.
	
How to save a text file:
	1. If the user would like to save their text file and it has not been saved before,
	the user would need to go to the file menu and then click save.
	2. It will treat it like a save as and the user will be asked where to save the new text file
	and what to call it.
	3. Else if the user has saved the file before and want to save changes to the file, they
	will go to the same file menu and click save
	4. If the user would want to save their file as new, they would go to the file menu
	and then click save as, where they will be prompted to set the name of the new file, and
	where they would want it located
	
How to run spell check:
	1. If the user would want to run the spell checker on their work, at the top menu,
	there will be a button that says run spell check.
	2. It will then turn blue showing the spell checker is active, and once it is done,
	a new menu next to it will show up called "Spell Check Suggestions".
	
How to replace a misspelled word:
	1. To replace a misspelled word, the user would need to click on the Spell Check Suggestions tab,
	and then it will list out all of the words that are misspelled.
	2. If you click on a word you would like to fix, a dropdown will show giving all the suggestions for
	that specific word.cancel
	
How the application handles unsaved changes:
	1. If the user has unsaved changes and they try to open a new file or they try to exit,
	they will then be prompted to save before doing those actions.
	
Known limitations:
	1. Can not ignore words
	2. Incorrect words, with no spelling suggestions, have an empty node show up in Spell Check Suggestions
